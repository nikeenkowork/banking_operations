# Приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение генерирует JSON-данные для веб-страниц, формировать
Excel-отчеты, а также предоставлять другие сервисы:

# Функция def main_page 
Обрабатывает входную дату и время пользователя и формирует
структурированный ответ с помощью функции build_main_response из модуля utils.

# Функция def events_page
Обрабатывает входной DataFrame с событиями и формирует структурированный 
ответ через функцию process_events из модуля utils.

# В модуле utils  
# Функция analyze_operations 
Читает Excel-файл operations.xlsx с помощью pandas
и преобразует его содержимое в структурированный JSON-совместимый формат.

# Модуль services
Представляет собой набор сервисов для анализа финансовых данных и
поиска информации в транзакциях, обеспечивая формирование структурированных
JSON-отчётов для дальнейшего использования в приложении.

# Модуль reports 
Модуль предназначен для анализа финансовых данных и формирования отчётов по
расходам пользователя, включая анализ по категориям, дням недели и типам дней
(рабочие/выходные).
